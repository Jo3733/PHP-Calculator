# 🧮 PHP Calculator

A simple web-based calculator built with **PHP, HTML, and CSS**.

This project was created as part of my Full Stack Developer learning journey to practice PHP fundamentals, form handling, conditional statements, and basic web development.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)
- Input validation
- Division by zero protection
- Responsive dark-themed interface

## 🛠️ Technologies

- PHP
- HTML5
- CSS3

## 📂 Project Structure

```text
calculator/
│
└── index.php
```

## ⚙️ How to Run

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd calculator
```

3. Start the PHP development server:

```bash
php -S localhost:8000
```

4. Open your browser:

```text
http://localhost:8000
```
